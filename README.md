# Basanth M

I build computational tools to ask sharper questions about space, physics, and engineering.

I'm a student in India interested in astrophysics, relativistic spaceflight, gravitational waves, and scientific computing. I like projects where the model is reproducible and its limits are as visible as its results.

## Featured work

### AETHER-BURN X · NASA Space Apps 2026

With **Team Orbitrace**, I worked on a research workbench for the *Flame in Freefall* challenge. It organizes microgravity combustion evidence and checks whether a result can be compared with a chosen scenario. The project keeps observations, calculations, model outputs, and missing evidence distinct. [Read the project case study](AETHER-BURN-X.md).

### Chasing Light, Breaking the Ship · Computational physics

How does shielding against interstellar material alter the mass and travel-time trade-off for a relativistic spacecraft? I built a coupled shielding and propulsion model with reproducible code, parameter studies, and physics consistency checks. [Explore the model](https://github.com/DrDoom751/Changing-Light-Breaking-the-Ship).

### Jajanken Showdown · Creative coding

A Hunter × Hunter-inspired browser game built with HTML, CSS, and JavaScript for CosHack. [Play from the source](https://github.com/DrDoom751/Rock-paper-scissor).
